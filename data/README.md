# mem-pressure.csv

MacBook Air M5 / 16GB 的内存压力采样，用来回答「要不要换更大内存」。

**采集期间**：2026-08-17 ~ 2026-09-08（3169 条，每 10 分钟一次）
**采集器已撤除**——问题已回答，不再采集。

## 结论

| 指标 | 平均 | 峰值 |
|---|---|---|
| swap 使用 | 835 MB | 14.4 GB |
| 压缩内存 | 6.8 GB | 25.1 GB |
| 空闲率 | 72% | 最低 17% |
| swap > 1GB 的采样 | 32.2%（1020 次） | |

**16GB 属于「紧但够用」**：压缩内存峰值 25GB、swap 峰值 14.4GB，
说明 macOS 靠压缩和换出在兜底；但空闲率始终没到崩溃线，最低 17%。
典型高压场景是「鸣潮 + Claude + Chrome」同时开。

**决定：保留 16GB。** 理由是苹果内存加价买不回等价体验，且两年内会换机。
