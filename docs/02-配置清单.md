### config/QueueConfig.json

| 队列 | 键 | 原值 | 现值 | 原因 |
|---|---|---|---|---|
| 新队列 | `AfterAccomplish` | `NoAction` | `Shutdown` | 跑完不关机，BIOS 唤醒就失去意义 |
| 新队列 | `StartUpEnabled` | `true` | `false` | **关键 bug**：见下方说明 |
| Evening-MAA | `AfterAccomplish` | `NoAction` | `Shutdown` | 同上 |

**`StartUpEnabled` 为什么必须关掉**

这个开关的语义是「AUTO-MAS 一启动就跑这个队列，不看时间」。开机这个动作，早上和晚上无法区分：

```
早上 08:45 开机 → AUTO-MAS 启动 → 新队列跑（MAA+MaaEnd）  ← 期望的
晚上 21:20 开机 → AUTO-MAS 启动 → 新队列又跑一遍！        ← 多余
                              21:30 → Evening-MAA 再跑 MAA
```

结果晚上会变成：明日方舟刷两遍（第二遍理智已空，纯空转）+ 终末地白跑一遍（并大概率报「协议空间失败」假警报）。

关掉后两轮都靠定时触发（09:00 / 21:30）。08:45 开机到 09:00 有 15 分钟余量，21:20 到 21:30 有 10 分钟余量。

### 开机自启（计划任务）

AUTO-MAS 的自启不是注册表 Run 项，而是一个**计划任务**：

```
任务名   AUTO-MAS_AutoStart
触发器   登录时（LogonTrigger）
权限     最高
```

`set_SelfStart()` 在程序每次启动时被调用，但实测**没能成功创建**该任务，已手动建立：

```powershell
schtasks /create /tn "AUTO-MAS_AutoStart" ^
  /tr "\"D:\Users\Administrator\Desktop\AUTO-MAS\AUTO-MAS.exe\"" ^
  /sc onlogon /rl highest /f
```

> ⚠️ 因为是**登录触发**，机器必须能无人值守自动登录到桌面。`AutoAdminLogon` 未显式配置，但账户为空密码，实测可自动进桌面。

## MaaEnd

路径：`D:\maaend\MaaEnd-win-x86_64-v1.6.5`

### config/mxu-MaaEnd.json

「全套日常」配置里挂了 **3 个 `__MXU_WEBHOOK__` 任务**，全部改为 `enabled: false`：

| 位置 | 内容 |
|---|---|
| `tasks[0]` | `...ftqq.com/****.send?title=short_title&desp=maaEND任务已开始` |
| `tasks[15]` | `...&desp=maaEND任务已结束` |
| `tasks[16]` | 同上（重复的副本 → 「已结束」会发两遍） |

**为什么不是"没配好"而是"配不出来"**：`__MXU_WEBHOOK__` 就是去 GET 一个写死的 URL，`title` 和 `desp` 硬编码在地址字符串里，**拿不到任何运行结果**。换谁配都只能发这一句。正确做法是关掉它，改用 AUTO-MAS 自带的通知。

> 编辑陷阱：`tasks[16]` 的 JSON 里 `taskName` 和 `enabled` 之间夹了个 `customName`，简单正则会漏掉它并误伤 `recentlyClosed`。改完务必做结构化 diff 核对。

## 电源设置

```powershell
powercfg /change monitor-timeout-ac 5     # 显示器 5 分钟休眠（原 300 分钟）
powercfg /change standby-timeout-ac 0     # 整机永不睡眠 ★ 动了任务就断
powercfg /change hibernate-timeout-ac 0   # 永不休眠
```

区分很关键：**显示器休眠不影响任务**（桌面照常渲染、ADB 照常工作），**整机睡眠会中断一切**。

AUTO-MAS 的 `Function.IfAllowSleep = false` 也在主动阻止系统睡眠。

MAA 刷理智全程走 ADB，不产生系统级鼠标输入，所以那 45 分钟屏幕会自动黑掉；MaaEnd 用前台控制器抢占鼠标，那段时间屏幕会一直亮，无法避免。

## SSH

- OpenSSH 用 [Win32-OpenSSH](https://github.com/PowerShell/Win32-OpenSSH) 独立 MSI 安装（`Add-WindowsCapability` 因组件存储损坏失败）
- 管理员账户的公钥必须放 `C:\ProgramData\ssh\administrators_authorized_keys`，**不是**用户目录
- 服务失败自动重启：
  ```
  sc.exe failure sshd reset= 86400 actions= restart/5000/restart/10000/restart/30000
  ```
