> 时间为**服务器（北京）时间**，括号内为东京时间。
> 最后更新：2026-08-15

## ⚠️ 三个已知问题

### 1. ~~日报大概率发不出去~~（已解决）

当时的原因：中继按 120 秒轮询，而队列完成到关机只有几秒。此后两步修掉：
中继改成**事件驱动**（记录一落盘立即处理），并且**关机权移交中继**
（`ARK_SHUTDOWN_AFTER_RUN=1` + AUTO-MAS 的 AfterAccomplish 改为不操作），
日报没发出去之前机器不关。保留此节作为历史记录。

### 2. 米家定时尚未设置

`08:40 断电 / 08:45 通电` 这两条**还在你 bro 手机上没设**。在设好之前，早上那轮不会自己开机。

但**晚上那轮不受影响**——BIOS 唤醒是主板自己的功能，不依赖米家。

### 3. 09:00 到 08:45 只有 15 分钟余量

开机 → 登录 → AUTO-MAS 启动，实测约 2 分钟，余量充足。但如果哪天 Windows 更新占用了开机时间，可能错过 09:00 的定时。

**目前没有补救机制**——`StartUpEnabled` 已被关掉（否则晚上会多跑一整轮）。云端中继上线后，可以由它检测「该跑没跑」并远程补触发。

## 核对清单

想验证这套是否按预期运行，查这几处：

```powershell
# 开关机历史（核对 BIOS 唤醒和自动关机）
Get-WinEvent -FilterHashtable @{LogName='System'; Id=6005,6006,1074} -MaxEvents 20 |
  ForEach-Object { $_.TimeCreated.ToString("MM-dd HH:mm:ss") + "  " + $_.Id }

# AUTO-MAS 有没有自启
Get-Process AUTO-MAS | Select-Object StartTime

# 中继有没有自启
Get-CimInstance Win32_Process | Where-Object { $_.CommandLine -like "*ark-relay*" }

# 当天跑了几轮、结果如何
dir "D:\Users\Administrator\Desktop\AUTO-MAS\history\<日期>" /s
```

中继日志：`C:\ProgramData\ark-relay\relay.log`
