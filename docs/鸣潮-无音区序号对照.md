# 鸣潮 无音区序号对照（未完成，方法已跑通）

**为什么需要它**：OK-WW 的 `Which Tacet Suppression to Farm` 只存一个**序号**，
它按游戏内列表从上往下数着传送（`TacetTask.py:96` → `click_on_book_target`）。
整个 OK-WW 项目里**没有任何一个无音区的名字**——全文搜过，「无音区」三个字
只在语言包里出现一次。上游自己的界面也是一个数字框，说明写着
`The Tacet Suppression number in the F2 list.`。
所以隔着一台机器改配置的人根本不知道 1234 是什么，用户 2026-09-04 的原话：
「给我标数字，我怎么知道 1234 是什么东西呢？这不是在搞笑吗？」

## 序号是哪个列表

对得上：OK-WW 的 `TacetTask.structure = [2, 5, 5, 7]`，
第一组「瑝珑·梦州」正好 2 个，四组合计 19 个。

## 怎么把剩下的补完：查库街区，不要开游戏

上面那张表是一屏一屏读游戏截图读出来的，慢，而且图标是从截图里抠的、
边缘永远带一圈黑。**这些东西库街区上全都有，而且 curl 直连就通。**

### 两个免登录接口

```
# 列表：catalogueId=1219 是「合鸣效果」，34 个套装
curl -s -X POST https://api.kurobbs.com/wiki/core/catalogue/item/getPage \
  -H 'wiki_type: 9' --data 'catalogueId=1219&page=1&limit=60'

# 详情：entryId 取自上面每条记录
curl -s -X POST https://api.kurobbs.com/wiki/core/catalogue/item/getEntryDetail \
  -H 'wiki_type: 9' --data 'id=<entryId>'
```

同一族的 `catalogue/config/getPage`、`getEntryDetailById`、`entry/detail`
都要令牌（`{"code":220,"msg":"访问令牌不能为空"}`），**只有上面这两个不要**。

### 图标

列表记录里 `content.contentUrl` 就是图标，76×76 原生透明 PNG，
图床 `prod-alicdn-community.kurobbs.com` curl 直连能下。
`web/app.js` 的 `SET_ICONS` 就是这么来的。

对照一下另一条路：鸣潮百科的 `wuwa.huijiwiki.com/wiki/Special:FilePath/<套装名>图标.png`
是 128×128 的透明图，质量更好，**但那两个域名 curl 一律吃 Cloudflare 挑战页**
（返回 6KB HTML 而不是 PNG，`file` 一看就知道），换 UA、加 Referer 都没用，
只能在浏览器里 fetch 再想办法搬回本机——下载会弹系统保存框要人点，
往本机 HTTP 服务器 POST 被页面 CSP 挡，反向直连 CDN 没有 CORS 头，
写剪贴板在沙箱里也落不到系统。**别再走这条路，走库街区。**

`getPage` 返回的顺序**就是游戏内合鸣筛选下拉的顺序：从新到老**。
`SET_ICONS` 按从老到新排，正好是它倒过来。
