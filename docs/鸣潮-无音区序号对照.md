# 鸣潮 无音区序号对照（未完成，方法已跑通）

**为什么需要它**：OK-WW 的 `Which Tacet Suppression to Farm` 只存一个**序号**，
它按游戏内列表从上往下数着传送（`TacetTask.py:96` → `click_on_book_target`）。
整个 OK-WW 项目里**没有任何一个无音区的名字**——全文搜过，「无音区」三个字
只在语言包里出现一次。上游自己的界面也是一个数字框，说明写着
`The Tacet Suppression number in the F2 list.`。
所以隔着一台机器改配置的人根本不知道 1234 是什么，用户 2026-09-04 的原话：
「给我标数字，我怎么知道 1234 是什么东西呢？这不是在搞笑吗？」

## 序号是哪个列表

游戏里按 **F2 → 素材获取 → 左栏「无音清剿」**。列表按地区分组，
**序号 = 从上往下第几个，跨组连续数**。

对得上：OK-WW 的 `TacetTask.structure = [2, 5, 5, 7]`，
第一组「瑝珑·梦州」正好 2 个，四组合计 19 个。

## 怎么把剩下的补完

* 列表滚动**用鼠标滚轮不动**（`wingui.sh scroll` 对这个面板无效），
  下次改用拖右侧滚动条，或用 OK-WW 自己的 `_find_book_scroll_top` 那套坐标。
* 套装名要**用筛选反查，不要看图标猜**：右上角「合鸣筛选」选一个套装，
  列表只剩含这个套装的无音区。已验证：**啸谷长风 → 只有 荒石高地无音区 I**。
  十几个套装各选一遍，就能得到完整的「套装 → 无音区」映射。
* 套装下拉里已看到的名字（还有更多要滚动）：凝夜白霜、熔山裂谷、彻空冥雷、
  啸谷长风、浮星祛暗、沉日劫明、隐世回光。

补完之后，手机页那两项改成带套装名的下拉，不再显示裸数字。
