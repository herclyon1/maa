# 运维手册

## 连接

```bash
ssh Administrator@$ARK_HOST
```

走 Tailscale，不需要端口转发。两端登录同一个 Tailscale 账号即可。

## 远程截图

SSH 会话没有桌面，必须通过计划任务在交互式会话里截：

```bash
ssh Administrator@$ARK_HOST 'schtasks /run /tn "ark-shot"'
sleep 4
scp Administrator@$ARK_HOST:'C:/ProgramData/ark-shot.png' ./now.png
```

## 远程操作（点击 / 输入 / 启动程序）

写动作文件 → 上传 → 触发：

```bash
cat > cmd.txt <<'EOF'
run D:\Users\Administrator\Desktop\AUTO-MAS\AUTO-MAS.exe
sleep 20000
click 264 345
sleep 2500
shot C:\ProgramData\s1.png
monitoroff
EOF
scp cmd.txt Administrator@$ARK_HOST:'C:/ProgramData/ark-cmd.txt'
ssh Administrator@$ARK_HOST 'schtasks /run /tn "ark-do"'
```

支持的动作：

| 动作 | 说明 |
|---|---|
| `move x y` | 移动鼠标 |
| `click x y` / `rclick x y` / `dclick x y` | 左键 / 右键 / 双击 |
| `type <SendKeys>` | 键盘输入，如 `type {ESC}` |
| `sleep <毫秒>` | 等待 |
| `run <路径>` | 启动程序 |
| `shot <路径>` | 全屏截图 |
| `monitoroff` | 关闭显示器（**放在最后**，之后任何鼠标动作都会把它唤醒） |

执行日志：`C:\ProgramData\ark-do.log`

## 查看运行记录

AUTO-MAS 每轮跑完写一份结构化记录：

```
D:\Users\Administrator\Desktop\AUTO-MAS\history\<日期>\<用户名>\<时-分-秒>.json
```

文件名 = 开始时间，文件修改时间 = 结束时间。内容：

```json
{
  "drop_statistics": {},
  "recruit_statistics": {},
  "sanity": 1,
  "sanity_full_at": "理智将在 2026-08-15 04:11 回满。(20h 44m 后)",
  "maa_result": "Success!",
  "maaend_result": "MaaEnd 部分任务执行失败: ⚔️协议空间"
}
```

同目录下的 `.log` 是完整运行日志。

读取时注意编码：文件是 UTF-8，但**路径里的中文目录名**经 SSH 返回时是 GBK。

## 检查机器有没有正常跑

```bash
ssh Administrator@$ARK_HOST 'powershell -NoProfile -Command "
  (Get-Date).ToString(\"yyyy-MM-dd HH:mm:ss\");
  (Get-CimInstance Win32_OperatingSystem).LastBootUpTime;
  Get-Process AUTO-MAS -ErrorAction SilentlyContinue | Select-Object StartTime
"'
```

开关机历史（用来核对 BIOS 唤醒时间是否生效）：

```powershell
Get-WinEvent -FilterHashtable @{LogName='System'; Id=6005,6006,1074} -MaxEvents 40 |
  ForEach-Object { $_.TimeCreated.ToString("MM-dd HH:mm:ss") + "  " + $_.Id }
```

`6005` = 开机，`6006` = 关机完成，`1074` = 关机请求。

## 改远程配置的标准流程

**永远不要直接在远端用正则改 JSON。** 流程：

1. 下载：远端 `[Convert]::ToBase64String([IO.File]::ReadAllBytes($f))` → 本地解码
2. 本地改（定位到目标块的文本范围内替换，不要全局替换）
3. 本地 `json.loads()` 校验
4. **结构化 diff**：改动前后都拍平成 `路径 → 值`，检查"新增 0 / 删除 0 / 改动 N"
5. 远端备份 `copy /Y ... .bak-YYYYMMDD`
6. `scp` 上传
7. 远端回读并再次 `ConvertFrom-Json` 校验

第 4 步不能省。见 [踩过的坑](05-踩过的坑.md#正则改-json-漏改并误伤)。

## 操作 macOS 上的 PlayCover 游戏

用 computer-use 驱动 PlayCover 里的 iOS 游戏（明日方舟等）时，有三条硬规矩，
都是实操中撞出来的：

**① 必须慢速按压，普通点击无效**

PlayCover 把鼠标事件翻译成触摸事件，一次性的 `left_click` 常常不被识别。
必须拆成：

```
mouse_move → left_mouse_down → 等 1 秒 → left_mouse_up
```

游戏内**所有**点击都要这样，包括关闭弹窗的小 X。曾经连点三次同一个关闭按钮
都没反应，换成慢速按压后一次成功。

**② 滚动无效，要用拖拽手势；而且要分清方向**

`scroll` 和一次性的 `left_click_drag` 都不管用，必须手动分解：

```
mouse_down → 中间插入 2~3 个 mouse_move → mouse_up
```

方向容易搞反，记牢：

| 拖拽方向 | 看到的内容 |
|---|---|
| 从右往左拖（1150 → 500） | 往**右**看（列表后面的内容） |
| 从左往右拖（500 → 1150） | 往**左**看（列表前面的内容） |

**③ 横向列表必须一屏一屏核，不能一口气滑到底**

活动商店是横向滚动的。连续三次大幅滑动会直接跳到最右端，**中间整整两屏被跳过**。
曾经因此漏掉一半商品，还报告说"已经搬空"。

正确做法：滑到最左端 → 截图 → 滑**一屏** → 截图 → 重复，直到最右端。
每屏都要看清才算数。

**④ 买东西之前先把全部清单看完**

代币有限时，先买的东西决定了后面买不到什么。曾经先买了家具（695 代币），
才发现后面还有更重要的作战记录和技巧概要，而代币已经不够了。

## 常见故障

| 现象 | 检查 |
|---|---|
| SSH 连得上但立刻断开、无 banner | 杀毒软件是否隔离了 `sshd-session.exe`。**这种情况只能人到现场** |
| 到点没跑 | AUTO-MAS 进程在不在；`AUTO-MAS_AutoStart` 计划任务在不在；机器有没有登录到桌面 |
| 「协议空间」失败 | 是不是有人正用 ToDesk 连着（被控端面板遮挡） |
| 通知一条都收不到 | AUTO-MAS 的通知是三层开关，见 [配置清单](02-配置清单.md) |
| 企业微信 `errcode=60020` | 调用方 IP 不在「企业可信IP」里 |
| 模拟器启动了但是错的实例 | 模拟器类型必须 `ldplayer` + `ldconsole.exe` |

## 电源

```powershell
powercfg /q SCHEME_CURRENT SUB_VIDEO VIDEOIDLE     # 显示器超时
powercfg /q SCHEME_CURRENT SUB_SLEEP STANDBYIDLE   # 整机睡眠（必须是 0）
powercfg /requests                                  # 谁在阻止休眠
powercfg /lastwake                                  # 上次是被什么唤醒的
```

**显示器休眠不影响任务，整机睡眠会中断一切。**
