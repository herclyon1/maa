## 企业微信推送不可用（自 README 迁入）

`errcode=60020`：调用方 IP 不在企业可信 IP 列表内。可在企业微信后台补录，
或改用群机器人并配置 `WECOM_BOT_URL`——群机器人没有可信 IP 名单。
当前全部推送由 Server酱 承担。

## 开机监督未启用（自 README 迁入）

机器未能开机这件事，机器自身无法发现，该检查放在 GitHub Actions
（`scripts/watchdog.py`）。启用需在仓库 Secrets 中配置
`TS_OAUTH_CLIENT_ID`、`TS_OAUTH_SECRET`、`SERVERCHAN_KEY`，
并将 `queue/watchdog.json` 的 `enabled` 改为 `true`。
