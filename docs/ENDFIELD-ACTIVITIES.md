# 终末地 活动中心

## 键位：活动中心是 F7，不是 F5

| 键 | 打开的界面 |
|----|-----------|
| F5 | 采购中心（商店，有真金白银的购买按钮） |
| F7 | **活动中心** ← 要看活动进度按这个 |
| F8 | 任务 |
| F9 | 武库 |
| B | 背包 |
| C | 干员 |
| ESC | 系统菜单 |
| TAB | 探索（大地图） |

键位不用猜也不用问——进游戏后右上角每个图标上面都印着自己的键，
截图裁 `1330,0,1920,100` 那块放大就能读出来。

## 侧边栏的橙色小方块 = 未读，不是未做

2026-08-29 实测：`根脉奇境`、`密境行者`、`协议邀约：重归` 三个都挂着橙点，
但点进去以后 `密境行者` 是 3 个空间组全 PERFECT、`根脉奇境` 是「奖励预览 已全部领取」。
点开一次橙点就消失了。

**判断做没做完只能看详情页右下角**：

- 有绿色的「已全部领取 ✓」= 这个活动榨干了
- 没有这行 = 还有东西没拿，得进去看
