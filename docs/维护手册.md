# 维护手册

给我自己看的：怎么部署、怎么改配置、提交前跑什么。
（README 是给人看的项目介绍，操作内容一律放这里。）

## 部署

中继部署到游戏机。它自己会跑全套测试、重建清单、逐个核对哈希、重启服务并确认起来了：

```bash
export ARK_HOST=100.65.39.119
scripts/mac/deploy-relay.sh
```

跑之前必须先写 `relay/RELEASE-NOTES.md`——那段文字就是推到手机上的更新说明，
不写会被拒绝部署（`lint-repo.sh` 第 5 项）。部署成功后它会自动清空，所以
**清单里 RELEASE-NOTES.md 的哈希和磁盘对不上是正常的**，第 14 道闸门排除了它。

手机页发布到 GitHub Pages：

```bash
scripts/mac/deploy-web.sh
```

改完代码只 push 不 deploy 的话，机器拿不到——清单和代码对不上时开机自更新会
认为「本机和清单一致」，不下载、不报错。第 14 道闸门就是拦这个的。

## 改配置

**不要直接编辑机器上的配置文件。** 三个游戏的配置有母本和副本之分，改错那份等于没改；
终末地和鸣潮的快速配置是关的，从 AUTO-MAS 侧改它们不生效。

* 规程：[CHANGE-CONFIG.md](CHANGE-CONFIG.md)
* 配置清单：[CONFIG.md](CONFIG.md)
* 查真正生效的值：`scripts/mac/winrun.sh --py scripts/mac/lib/effective_config.py`

日常改设置走手机页；命令行改走 `scripts/mac/order.sh`：

```bash
scripts/mac/order.sh '{"action":"debug_mode","minutes":90}'   # 下一条指令
scripts/mac/order.sh --clear                                   # 做完清空
```

**别直接手改 `queue/config.json`**。它是整份重放的：上一条留在里面，
下次为了改别的抬版本号时会跟着再执行一遍。而且中继取它走 jsDelivr，
不清缓存指令就到不了机器，屏幕上和 GitHub 上却都是对的。
`order.sh` 把这两件事都做掉了——覆盖式写入、推完清缓存并等到各扇门真发新版本。

## 提交前

两个硬闸门，都要绿：

```bash
scripts/mac/lint-repo.sh
```

```bash
scripts/mac/guardcheck.sh
```

后者验证那些闸门本身还活着——**闸门坏了不出声，比没有闸门更糟**，
所以它拿已知的坏样本去喂每一道闸，断言必须被拒。

### `lint-repo.sh` 的 19 项分别是什么

| # | 查什么 | 底下是谁 |
|---|---|---|
| 1 | shell 脚本静态检查 | `shellcheck -S warning` |
| 2 | 不许用 PowerShell 5.1（要 pwsh 7） | 正则 |
| 3 | ssh 送 PowerShell 必须走 base64 | 正则 |
| 4 | 脚本目录必须在 `cd` 之前算好 | 正则 |
| 5 | 部署清单要包含更新说明 | 正则 |
| 6 | 中继测试全绿 | `relay/tests/*.py`，并行跑 |
| 7 | 没有永远不会被执行的代码 | `scripts/mac/lib/deadcode.py` |
| 8 | 手机页文案不许有私人措辞 | 正则，规矩在 `手机页文案的规矩.md` |
| 9 | 静态检查 | `pyflakes` + 机器那版 Python 3.14 严格编译 |
| 10 | 测试语料必须入库 | 数文件，防 `.gitignore` 把夹具挡在库外 |
| 11 | 中继的状态只能由中继自己写 | 正则 |
| 12 | 公开仓库里不许有他人身份信息 | 正则 |
| 13 | 文档和脚本都要有入口 | 逐个 `docs/*.md`、`scripts/**` 反查引用 |
| 14 | 部署清单要和代码对得上 | 比 `relay/manifest.json` 的哈希 |
| 15 | 文档说的和代码做的对得上 | `scripts/mac/check-docs.py --local` |
| 16 | 日志名要等于 `ark.<模块名>` | `scripts/mac/lib/loggernames.py` |
| 17 | 测试里 `check()` 只准有一个意思 | `scripts/mac/lib/checkshape.py` |
| 18 | 指向 CODE-HISTORY 的锚点唯一、话说完 | `scripts/mac/lib/history-anchors.py` |
| 19 | 每条 `# noqa` 都真的压着一条规则 | `ruff check --config ruff.toml`（RUF100） |

规则的取舍和「为什么不选 SLF001/S310/S603」写在 `ruff.toml` 的注释里。
