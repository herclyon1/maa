# 回放样本库（根治第 2 项）

机器上真实跑出来的运行记录，原样（脱敏后）存在这里；所有「判断」函数改动前后都要
过一遍回放，结果和 `expected.json` 逐项比对。**新 bug 先加样本、看它红，再修。**

目录：`tests/replay/<日期>/<账号>/<脚本>-HH-MM-SS.json` + 同名 `.log`，
同一目录下 `expected.json` 记每条记录的判定：`ok`、`failed_tasks`、以及 `raw` 里
挑出来的字段（`okww_steps`、`okww_unreachable`、`okww_error`、`maaend_name_mismatch`、
`tasks_failed` 等）。

拉样本：`scripts/mac/pull-replay.sh 2026-09-07`（机器开着时），会把那天的 history
拷过来、脱敏、并用**当前**解析器生成 `expected.json` 草稿——草稿要人看过再提交，
看的就是「这样判对不对」。
跑回放：`python3 tests/test_replay.py`（也在全套测试和 lint 里）。

## 现在有哪几天，各覆盖什么（2026-09-08 扩到 4 天 42 条）

原来只有一天 10 条，等于「只验过一种天气」。挑的这几天都带着**已经出过事的形状**：

| 日期 | 条数 | 里面有什么值得钉住的 |
|---|---|---|
| 2026-09-01 | 22 | 鸣潮周本打完 Boss 卡在结算页退不出来，一晚上撞了十来趟（补丁 v5 修的就是这个）；夹着两条 AUTO-MAS 自己判的「在完成任务前退出」和一条 500 行 `WaitFailedException` 的「等一个画面没等到」；终末地「赠送干员礼物」失败 |
| 2026-09-04 | 5 | 终末地基质刷取失败→重试成功（刷错地区那个 bug 还在的时候） |
| 2026-09-05 | 5 | 同上，这是改成藏剑谷/清波寨的前一趟 |
| 2026-09-07 | 10 | 平常的一天：三个脚本都跑、周本领了一次之后没退出 |

每条 `expected.json` 都逐条看过：核对过 `general_result` 是 AUTO-MAS 自己写的原话、
`WaitFailedException` 确实在日志里、失败任务名和当天记的事故对得上。
**它记的是「该怎么判」，不是「现在怎么判」**——改判定逻辑时如果这里红了，
先想清楚是逻辑对了还是样本该更新，别顺手改 expected。
