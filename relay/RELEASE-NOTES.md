- 关机命令被 Windows 拒绝时不再当成已经关机：会报到群里，下一轮再关。
- 读不到正在运行的程序列表时，按「不知道」处理：等游戏登录界面时接着看屏幕；不去重新打开调度程序，日志里照实写「读不到」，不再写成「安装程序正在运行」。
- 中继日志 relay.log 不再一直变大：满 16 MB 换一份新的，最多留 3 份旧的；每日上传、证据包、开机核对照样读得到换下来的那一段。
- 自更新改成全部新文件先放进暂存区，全都写好才一起换上；中途出错，原来的文件一个都不动，并且会报出来。文件校验从 SHA-1 换成 SHA-256。
- 明日方舟的卡池公告和维护公告改从官网的接口读，不再抠网页。
- 终末地维护公告有好几条时，取最新的那一条。
- 手机信箱关闭时不再干等下一次心跳（Windows 上也是）。
- 机器关得太久、手机发来的指令已经过期丢掉时，记下丢在哪一段时间，手机上看得到。
- 日志换份失败后，中继会自己把日志重新打开，不会从此不写。
- 当天日志太大要截断上传时，截点正好在行首不再多丢一整行。
