# MAA 无人值守自动化

一台在国内的 Windows 游戏机，每天自己开机两次，跑完明日方舟和终末地的日常，
把结果推到微信，然后自己关机。控制端是日本的 Mac，通过 Tailscale + SSH 遥控，
但**控制端关着也不影响它自己跑**。

被自动化的是 [MAA](https://github.com/MaaAssistantArknights/MaaAssistantArknights)（明日方舟）
和 [MaaEnd](https://github.com/MaaEnd/MaaEnd)（终末地），由
[AUTO-MAS](https://github.com/AUTO-MAS-Project/AUTO-MAS) 统一调度；
`relay/` 是我写的中继，负责判定、推送和关机。

## 一、机器每天在干什么

时间是**服务器时间（北京）**，括号里是东京时间。

```
08:40 断电 →  08:45 通电，自动开机  (09:45)
09:00 跑「新队列」：明日方舟 → 终末地，约 85 分钟   (10:00)
10:30 汇报 → 自动关机                              (11:30)
      ── 白天 11 小时完全关机，这段时间机器上的任何东西都看不见它 ──
21:20 BIOS 定时自己开机                            (22:20)
21:30 跑「Evening-MAA」：只跑明日方舟，约 45 分钟   (22:30)
22:20 发当天日报 → 自动关机                        (23:20)
```

一天只醒着约 3 小时。明日方舟必须一天两次分开刷，否则基建溢出。

**当前设置**：关卡 `1-7`，理智药 `0`（不吃药），剿灭 `Close`，
终末地刷「干员养成 · 干员经验」。

## 三、要你动手的三件事

我做不了，或者不该替你做。

### 1. 米家插座的定时还没设 ⚠️

`08:40 断电 / 08:45 通电` 这两条定时**还在你 bro 手机上没设**。
没设之前，**早上那轮不会自己开机**。晚上那轮不受影响，BIOS 唤醒是主板自己的功能。

### 2. 企业微信通知是坏的（errcode 60020）

家宽拨号 IP 变了，企业微信自建应用只接受「企业可信IP」名单里的调用。两条路选一条：

- **临时**：去企业微信后台把当前出口 IP 加进可信 IP。
  具体是哪个 IP，60020 那条告警里会直接写出来（本仓库公开，不写具体地址）。
  家宽拨号 IP 一变还会再坏一次。
- **一劳永逸**：建一个**群机器人**，把 webhook 地址给我，我填进 `WECOM_BOT_URL`。
  群机器人没有可信 IP 名单，家宽 IP 怎么变都不影响。

修好之后 Server酱 和企业微信会**同时推**，到时候关掉一个。

### 3. 开机监督还没启用

「机器该开机却没开机」这件事，机器自己永远发现不了——它没开机。
这个检查放在 GitHub Actions 上（`scripts/watchdog.py`），已经写好了但**没启用**，
需要你在仓库 Settings → Secrets 里加三个值：

```
TS_OAUTH_CLIENT_ID
TS_OAUTH_SECRET
SERVERCHAN_KEY
```

然后把 `queue/watchdog.json` 里的 `enabled` 改成 `true`。

> 要故意让机器整晚开着调试时，先把 `watchdog.json` 的 `pause_until` 改到那天，
> 否则半夜会告警「该关机还在线」。

## 四、你怎么给机器下指令

改这个仓库里的 [`queue/config.json`](queue/config.json)，机器**下次开机时**自己读到、
应用、然后微信通知你结果。改完**必须把 `version` 改大**，否则机器认为没变化。

写法、能下哪些指令、终末地刷什么怎么选，全在 [`queue/README.md`](queue/README.md)。

手机上直接在 GitHub 网页里改这个文件就行，不需要装任何东西。

## 五、我必须守的规矩

你下过的死命令，写在这里是为了让它们跑不掉：

1. **没有你的命令不许关机。** 中继跑完自动关机是既定设计，不算在内。
2. **改配置压过按时开跑。** 宁可晚刷，也绝不用旧配置跑。
3. **更新必须立即生效。** 推送完立刻重启服务，不许等下次开机。
4. **方案不等于开工令。** 我说了打算怎么做，要等你明确同意才动手。
5. **不许默认用轮询。** 确实没有事件驱动的路，先跟你说明理由并取得同意。
6. **你不在 Mac 跟前时不动它的网络。**
7. **别人机器上的调试残骸当次清理干净。**

## 六、这个仓库里有什么

| 目录 | 是什么 |
|---|---|
| `relay/` | 中继源码，跑在游戏机上 |
| `queue/` | **你改的地方**：给机器的指令、开机监督的配置 |
| `scripts/` | Mac 侧和 Windows 侧的工具脚本 |
| `docs/` | 英文，我自己看的操作参考和故障记录 |

`scripts/mac/check-docs.py` 会核对文档里写的东西和真实情况是否一致——
文档写错了它会指出来。**文档不许和事实脱节**，发现不一致就是 bug。
